# QRandomPicker

一个基于 Qt 的桌面应用程序，用于管理多组名单并执行随机或公平抽取。支持会话管理、多种视图模式、历史记录、小窗模式，所有数据自动持久化。

## ✨ 主要功能

- **会话管理**  
  - 新建、复制、打开、关闭、删除会话  
  - 每个会话独立存储名单、抽取模式、抽取次数和视图偏好  
  - 会话数据自动保存为 JSON 文件（`sessions/*.json`）

- **抽取模式**  
  - **随机模式**：从名单中随机抽取指定人数，可重复抽取  
  - **公平模式**：确保每个人被抽中一次后才开始下一轮，自动重置

- **名单编辑**  
  - 支持从文本文件导入（每行一个名字）  
  - 手动编辑、去重、清空

- **界面布局**  
  - **简洁模式**：仅显示抽取结果和控件  
  - **正常模式**：左侧显示名单列表，右侧结果区  
  - **高级模式**：额外显示抽取历史与统计信息（总人数、累计抽取次数、公平模式剩余人数）

- **历史记录**  
  - 记录每次抽取的时间、模式、人数和具体名单  
  - 支持清空历史

- **小窗模式**  
  - 无边框浮动窗口，可拖动、置顶、最小化  
  - 适合在演示或上课时保持前台显示

- **全局快捷键**  

## 🛠️ 构建依赖

- Qt
- 编译器：支持 C++17 

## 🖥️ 使用说明

### 首次启动
- 程序会在当前目录下创建 `sessions/` 文件夹用于存储数据。
- 默认无会话，通过 **文件 → 新建会话** 创建。

### 创建会话
- 输入会话名称（不可重名）。
- 编辑名单（每行一个名字，支持从 `.txt` 文件导入）。
- 选择抽取模式（随机/公平）和每次抽取人数。

### 抽取
- 点击 **开始抽取**。
- 结果会以网格形式显示在右侧区域，自动适应窗口大小。

### 切换视图
- 通过 **视图** 菜单切换简洁/正常/高级模式。
- 高级模式显示历史列表和统计面板。

### 小窗模式
- **视图 → 小窗模式** 打开独立小窗。
- 标题栏提供返回、置顶、最小化、关闭按钮。
- 窗口可拖动（拖拽标题栏）。

### 数据持久化
- 每次修改会自动保存到对应的 `sessions/<uuid>.json` 文件。
- 可手动执行 **文件 → 保存当前会话** / **保存所有会话**。
